causalis.dgp.causaldata_instrumental.functional¶

High-level helpers for instrumental-variable synthetic datasets.

Use this module when you want a ready-made binary-instrument, binary-treatment dataset compatible with :class:causalis.data_contracts.iv_causal_data.IVCausalData. For lower-level structural control, instantiate :class:causalis.dgp.causaldata_instrumental.base.InstrumentalGenerator directly.
