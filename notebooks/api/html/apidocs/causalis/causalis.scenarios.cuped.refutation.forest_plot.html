Forest plot of absolute estimates and CIs for CUPED vs non-CUPED.

Parameters

If omitted, the function uses estimate_with_cuped.diagnostic_data.ate_naive and estimate_with_cuped.diagnostic_data.se_naive to build a normal-approx CI.
